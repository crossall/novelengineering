이야기 밖에서 마음대로 정한 조건은 제약이 아니에요. 제약마다 "책의 어느 문장 때문에?"를 붙여야 해요.

#종류제약 내용근거 문장

3. 문제 정의문

교사 노트. 익명 문제 보드에서 고른 문제 하나를 가져와 모둠별로 채웁니다. 제약 표는 처음에 "가져오기"로 두 개쯤 채워 보여 주고, 나머지는 학생이 원문을 검색해 직접 붙이게 합니다. 저장 단추가 꺼져 있는 이유를 학생이 스스로 읽고 고치는 장면이 이 앱의 핵심입니다. 관찰 포인트: 제약을 "늑대를 없앤다" 같은 해결책으로 쓰는지, "늑대는 포기하지 않는다"처럼 조건으로 쓰는지. 근거 문장을 찾지 못하는 제약은 대개 학생이 이야기 밖에서 가져온 가정입니다 — 그때 "책에 없으면 우리가 정한 가정이라고 표시하자"고 안내합니다. 명세: 기능 — 누가/무엇이/왜 입력, 왜의 근거 검색 선택, 제약 표(종류·내용·근거) 행 추가·삭제, STORY.constraints 가져오기, 검증 결과에 따라 저장 단추 켜기/끄기와 부족한 행 목록 표시, 저장 시 정의문 문단 생성과 복사, localStorage 자동 저장. 입력 — 인물(select), 필요·이유(빈 값 거부), 제약 행(종류 select, 내용 빈 값 거부, 근거 1개 이상 필수). 출력 — "[인물]은(는) [근거] 때문에 [필요]가 필요하다. 단, [제약…]을 지켜야 한다." 문단과 근거 배지. 성공 조건 — 근거가 없는 행이 하나라도 있으면 저장되지 않고 정확히 어느 행이 부족한지 보인다. 새로고침해도 입력이 남는다.
