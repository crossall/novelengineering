# 노벨 엔지니어링 × 바이브코딩 — 아기돼지 삼형제

> 구현을 넘기고, 정의와 검증을 남기다.

초등교사 대상 강의 「노벨 엔지니어링과 바이브코딩」에서 참여자에게 보여주는 예시 앱 모음입니다.
「아기돼지 삼형제」 한 권을 소재로, 노벨 엔지니어링(NE) 여섯 단계마다 **교사가 만드는 것**과 **학생이 만드는 것**을 하나씩 실제로 만들었습니다.

**바로 보기:** https://crossall.github.io/novelengineering/

## 척추 문장

교사는 학생의 사고를 **열거나**(체험·시뮬레이션) **닫게**(기준·검증 도구) 만드는 장치를 만들고,
학생은 **정의와 검증**이라는 수렴을 맡는다. 학생이 직접 만들 때도 명세와 검증은 학생 몫이다.

## 구성

| 단계 | 요구 사고 | 교사가 만드는 것 | 학생이 만드는 것 |
|---|---|---|---|
| 1 책 읽기 | 상황 모형(수렴), 관점 취하기 | `01-reading/interview-bot.html` 인물 인터뷰 챗봇 · `constraint-cards.html` 제약 카드 생성기 | `relations-timeline.html` 인물 관계도·사건 타임라인 |
| 2 문제 인식 | 확산(열거) → 수렴(정의), 연역 | `02-problem/problem-sims.html` 체험 시뮬레이션 · `problem-board.html` 익명 문제 보드 · `problem-worksheet.html` 문제 정의 워크시트 | `sim-builder.html` 내가 만드는 시뮬레이션 |
| 3 해결책 설계 | 확산(대안), 수렴(기준), 가추 | `03-design/decision-matrix.html` 의사결정 매트릭스 · `constraint-deck.html` 탈고착 제약 카드 | `three-prototypes.html` 아이디어 3개, 선택 1개 |
| 4 창작물 만들기 | 명세, 분해, 검증, 메타인지 | `04-make/spec-template.html` 명세서 템플릿 · `verify-cards.html` 검증 카드 | `spec-to-prompt.html` 명세→프롬프트→실행→검증 · `sensor-logic.html` 늑대 감지 장치 |
| 5 피드백·개선 | 귀납, 성찰적 의사결정 | `05-feedback/gallery.html` 3기준 갤러리 피드백 + 교사 대시보드 | `prompt-history.html` v1→v2 성찰 |
| 6 이야기 재구성 | 반사실적·인과 추론 | `06-rewrite/event-graph.html` 원작 사건 그래프 · `contradiction-check.html` 모순 지적기 | `branching-story.html` 분기형 이야기 앱 |

## 설계 원칙

- **서버 없음.** 모든 앱은 HTML 파일 하나로 브라우저에서만 돌아갑니다. 데이터는 그 브라우저의 localStorage에만 남습니다.
- **텍스트가 근거.** `shared/story.js`의 문장 43개가 유일한 원문입니다. 앱이 이야기의 사실을 말할 때는 "문장 12" 배지를 붙이고, 배지를 누르면 원문이 뜹니다. 챗봇도 이 문장만 인용하며, 없는 것은 "책에 없어요"라고 답합니다.
- **사고가 일어나는 지점이 UI에 보이게.** 근거 없이는 저장이 안 되고, 검증 없이는 완료가 안 되고, 정당화 없이는 선택이 안 됩니다.
- **AI 키 없음.** "AI가 모순을 지적한다" 같은 기능은 규칙 기반으로 흉내 냈습니다. 실제 AI가 필요한 곳(4단계 학생용)은 프롬프트를 복사해 외부 AI에 보내고 결과 코드를 붙여 넣어 실행하는 방식입니다.

## AI 연동 (선택)

세 앱은 Anthropic API 키가 있으면 실제 Claude를 씁니다. 키가 없어도 모든 앱은 규칙 기반으로 동작합니다.

| 앱 | AI가 하는 일 |
|---|---|
| 1단계 인물 인터뷰 챗봇 | 인물이 되어 답하되, 원문 43문장만 근거로 쓰고 사실마다 (문장 N)을 붙임. 없으면 "책에 없어요" |
| 4단계 명세→프롬프트→실행→검증 | 프롬프트를 바로 보내 HTML을 받아 실행. 되돌아간 뒤에는 이전 코드와 실패한 검증 카드를 함께 보내 고치게 함 |
| 6단계 모순 지적기 | 규칙 검사 위에 Claude의 지적(모순/질문, 근거 문장 번호)을 더함 |

**키 넣는 법.** 페이지 오른쪽 위 "AI 설정"에 키를 붙여 넣고 "연결 확인"을 누릅니다. 키는 그 브라우저의 localStorage에만 저장되고, 요청은 브라우저에서 Anthropic API로 직접 갑니다. 공용 컴퓨터에서는 쓰고 나서 "키 지우기"를 누르세요.

**강사 컴퓨터에서 매번 넣지 않으려면** `shared/ai.local.example.js`를 복사해 `shared/ai.local.js`로 저장하고 키를 넣습니다. 이 파일은 `.gitignore`에 있어 저장소에 올라가지 않습니다. 공개 저장소이므로 키를 코드에 넣어 커밋하면 즉시 유출됩니다.

기본 모델은 `claude-sonnet-5`이며 AI 설정에서 Haiku 4.5, Opus 5로 바꿀 수 있습니다. 구현은 `shared/ai.js` 한 파일입니다(SDK 없이 `fetch`로 Messages API 호출).

## 로컬에서 보기

정적 파일이므로 `index.html`을 브라우저로 열면 됩니다. 일부 브라우저는 `file://`에서 iframe 실행을 막으므로 간단한 서버를 권합니다.

```
npx serve .
```

## 원문에 대하여

「아기돼지 삼형제」는 저작권이 없는 민담입니다. `shared/story.js`의 본문은 Joseph Jacobs 판본(순무밭·사과나무·장터 삽화 포함)을 바탕으로 수업용으로 새로 쓴 재화입니다.
